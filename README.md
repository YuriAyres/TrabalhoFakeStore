# 📱 App React Native – Fake Store API

## 🚀 Como rodar o projeto com Expo

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o projeto:

```bash
npx expo start
```

4. Execute no celular ou emulador:

* 📱 App Expo Go (Android/iOS) → escaneie o QR Code
* 💻 Emulador Android/iOS → abrir pelo terminal
